## 读取边界

- 用户尚未提交作答、只问原文 / 词义 / 句法 / 选项翻译时：不得读取本目录。
- 用户提交答案要求核对，或明确要求答案、解析、复盘、讲题时：只读取对应年份、Text 和题号所需页。
- OCR 只是定位辅助，不作为出版方解析的可靠转写；具体讲解应回看原 PDF 视觉页。
- 本目录不得被复制进 `articles/`、Tutor 输入、`master_bank.csv` 或 `sentence_patterns.md`。

## 构建说明

逐页使用 150 dpi 图像和 Tesseract `eng --psm 6` 建立定位文本；临时页面图像已删除，只保留 128 个逐页文本文件。OCR 错字不做语言提升，也不用于生成练习答案。

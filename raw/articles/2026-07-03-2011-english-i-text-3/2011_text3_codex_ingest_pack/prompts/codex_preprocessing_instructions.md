# Codex 预处理指令｜2011 英语一 Text 3

## 任务范围
仅处理 2011 年考研英语一 Reading Comprehension Part A 的 Text 3。不得把 Text 2 或 Text 4 内容混入知识库。

## 初始交互规则
本包包含答案、错项分析和详细解析，但学习者明确要求：在复盘前不要看到任何答案或解析。因此：

1. 初次回答学习者关于本篇的练习请求时，只展示文章、题目或定位提示，不展示正确选项。
2. 学习者提交自己的答案后，可按题号逐题核对。
3. 学习者明确说“复盘 / 解析 / 答案 / 讲解 / 错题分析”后，才可以展示 `correct_answer`、`解析`、`错项分析` 字段。
4. 学习者问词汇、长难句、段落结构时，可以讲对应内容，但避免泄露选择题答案。

## 推荐切片策略
- paragraph_chunk: 按 P1-P4 切分文章，每段保留英文、中文译文、句际逻辑、词汇。
- question_chunk: Q31-Q35 单独切片，每题保留题干、选项、定位、答案、解析、错项分析；答案字段打上 hidden_until_review。
- concept_chunk: media_taxonomy 单独切片，用于回答概念题和总结题。

## 可视化源文件
`source_pages/` 中为 Text 3 相关页面截图或裁剪图；仅作为 Codex 校验原文排版、题目和解析来源使用，不要在聊天界面直接展示。

## 主旨压缩
Text 3 的核心是：传统 paid media 之外的替代/补充媒介正在改变营销效果来源；earned、owned、sold、hijacked media 分别带来机会与风险。

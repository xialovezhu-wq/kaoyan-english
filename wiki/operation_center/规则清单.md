# 英语 LAMBIC 规则清单

更新时间：2026-07-11

本清单记录英语专项 LAMBIC 系统当前必须遵守的规则来源。若同一事项冲突，优先级为：用户当前明确边界 > 英语系统项目规则 > 第二大脑四系统集成规则 > 本清单。

## 本仓库规则来源

| 文件 | 角色 | 当前结论 |
|---|---|---|
| `prompts/codex_prompt.md` | 英语系统最高优先规则 | 负责文章精读、错句、CSV、句式卡、review 和答案披露规则 |
| `schema/schema.md` | 三层架构规则索引 | 补充 raw / wiki / schema、ingest / query / lint、自动化边界 |
| `schema/video_ingest_template.md` | 视频语库导入模板 | 规定字幕、视频笔记、NotebookLM 输出先进入 raw/wiki |
| `schema/reference_grounded_examples.md` | 生词例句四层地基规则 | 用户措辞或错词证据、approved / corrected 作文句型与词组、verified 大纲 occurrence 必须可追溯；生成句不得冒充来源原句 |
| `wiki/reading/历年真题阅读总索引.md` | 历年阅读总入口 | 60 篇 practice-safe 原文、题目和选项；答案保持隐藏 |
| `wiki/vocabulary/大纲词汇参考库.md` | 大纲词汇参考入口 | OCR / 词头参考，不自动写长期词库 |
| `wiki/writing/作文资料总索引.md` | 作文资料参考入口 | 自动候选与审核白名单分层，不复用 rejected 原文 |
| `wiki/index.md` | 英语 LLM Wiki 总入口 | 登记 articles、bank、review、video、schema 等入口 |
| `wiki/log.md` | 维护日志 | 记录框架、lint、验收和同步动作，不替代复习日志 |
| `raw/index.md` | 原始来源登记 | 只登记 raw source，不做精翻、不做长期库判断 |
| `wiki/video/README.md` | 视频语库规则 | 视频候选先留在 wiki，少量精选才可进入 CSV |
| `bank/sentence_patterns.md` | 句式卡规则源 | SP 卡片字段和骨架受控，归并优先于新建 |
| `bank/master_bank.csv` | 长期结构化库 | 13 列固定；本目标期间只读，不写入 |
| `review/tomorrow_review.md` | 临时复习清单 | 可用于复习状态，不是长期 master source |
| `review/weekly_review.md` | 周复盘 | 本目标期间不更新，除非用户明确要求周复盘 |

## 技能规则来源

| Skill | 用途 | 使用边界 |
|---|---|---|
| `defuddle` | 网页清洗为 Markdown | 只用于网页 raw 导入；不直接写 CSV |
| `obsidian-cli` | vault 搜索、读取、Bases 查询 | 用于验收和索引可见性；不绕过项目规则写正式数据 |
| `obsidian-bases` | `.base` 看板 | 看板是视图层，不是源数据层 |
| `tutor-setup` | 由精选资料生成 StudyVault | 不直接扫描成熟系统根目录；先准备小专题输入材料 |
| `tutor` | 主动回忆测验 | 结果只同步薄弱点摘要，不反写 CSV |

## 当前硬边界

1. 不修改 `bank/master_bank.csv`，除非用户明确要求精选入库。
2. 不更新 `review/weekly_review.md`，除非用户明确要求周复盘。
3. 不批量把普通生词塞进长期库。
4. 不把 Tutor 训练结果自动改写为 CSV 条目。
5. 保留历史文件。原搭建任务的“不提交远端”仅限其当时范围；已明确批准的完整私有学习库发布按现行本科出口执行，失败不重放正式写入。

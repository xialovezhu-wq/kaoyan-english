# Tutor 接入方案：长难句限定条件与转折逻辑

更新时间：2026-06-28

## 定位

本专题是英语系统首批 Tutor 接入样本，用于主动回忆训练“限定条件、转折逻辑、让步关系、原因条件和结构反转”。它不替代文章精读、`bank/master_bank.csv` 或 `bank/sentence_patterns.md`。

## 边界

- 不批量处理普通生词。
- 不导出选择题标准答案作为测验材料。
- 不把 Tutor 训练结果自动改写为 CSV。
- 不改 `review/weekly_review.md`。
- 训练结果只同步薄弱表达、结构误判和候选跨系统模式。

## StudyVault 位置

推荐位置：

`wiki/study_vaults/long-sentence-conditions-turns/StudyVault/`

当前先建立输入候选，不直接运行 `tutor-setup`。如果后续要生成 StudyVault，先把 `input_candidates.md` 拆成小专题材料，再由 `tutor-setup` 在本仓库内处理。

## 训练题型设计

| 题型 | 目标 | 示例任务 |
|---|---|---|
| 主干识别 | 先跳过限定成分抓主干 | 给出长句，要求指出主句主语、谓语和核心判断 |
| 逻辑关系判断 | 区分条件、让步、原因、转折 | 判断 `as / unless / but / yet / however` 在句中功能 |
| 修饰对象定位 | 找出定从、后置短语修饰谁 | 判断省略引导词定从修饰的名词 |
| 结构转写 | 把复杂结构转成中文动作提醒 | 用一句话说明“下次看到这种结构先做什么” |
| 错因回忆 | 复现用户历史错点 | 从文章错句记录中抽结构误判，不抽普通生词 |

## 跨系统候选

- 条件意识：英语 `unless / if / as long as` 与数学“条件边界”、408“状态转移条件”可形成候选关系。
- 转折意识：英语 `but / yet / however` 与数学“反例/分类分支”、408“例外条件”可形成候选关系。
- 限定意识：英语定语从句和介词短语限定对象，与数学“变量范围”、408“适用场景”可形成候选关系。

这些只作为候选同步到第二大脑，不能直接写成稳定规律。

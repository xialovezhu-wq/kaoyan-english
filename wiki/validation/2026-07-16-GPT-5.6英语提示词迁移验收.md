# GPT-5.6 英语提示词迁移验收

## 结论

英语生产提示栈已按 OpenAI 官方 [Prompting guidance for GPT-5.6 Sol](https://developers.openai.com/api/docs/guides/prompt-guidance-gpt-5p6) 完成迁移。

本地真实 A/B 使用 `gpt-5.6-sol` 与 `model_reasoning_effort="ultra"`。官方页面中的模型名称是 GPT-5.6 Sol，Ultra 是本次测试使用的推理强度。

最终结果：

- 新版行为断言：12 / 12 PASS。
- 旧版行为断言：7 / 12 PASS。
- 新版聊天排版门禁：4 / 4 PASS。
- 旧版聊天排版门禁：1 / 4 PASS。
- 总输入 token：296,823 降至 127,049，下降 57.2%。
- 平均执行时间：44.171 秒降至 39.923 秒。
- 核心提示：1,144 行 / 47,171 bytes 收敛为 243 行 / 14,094 bytes，字节数下降 70.1%。
- 四个最终入模指令栈合计：284,893 bytes 降至 147,327 bytes，下降 48.3%。

## 官方指南落地方式

本次保留的是结果与门禁，删减的是重复流程和快照信息。

现行结构统一为：

1. Role。
2. Personality and collaboration。
3. Goal。
4. Success criteria。
5. Authorization / Constraints。
6. Tools。
7. Output。
8. Stop rules。
9. Validation。

关键收敛：

- 核心提示只保留跨任务不变量与路由，专项细节交给单一 schema 或 skill reference。
- 不再在提示中固定 94 个 occurrence、25 个句型等可变快照，改为运行时查 manifest 和 selector。
- 默认只加载当前任务所需文件，不强制逐次读全部 index / log / sibling skills。
- 独立读可并行，依赖步骤串行；缺字段、证据或授权时显式停止。

## 主要行为修复

### 答案保护

- practice-safe article 不存答案、正确选项或出版方解析。
- 用户只陈述自己的选项不解锁答案。
- 只在明确要求核对答案、讲题或进入复盘时，读取对应题号的最小受保护块。
- 单纯要求保存答案材料时，可以存受保护层，但聊天回执不重复答案。

### 学习模式

- 首轮原样引用用户第一遍翻译。
- 没有证据时不虚构用户的第一动作、错因或掌握度。
- 观察和不确定点使用陈述句；不再先用“是否 / 能否 / 怎么”暗问一遍，再正式提问。
- 每轮只有一个诊断问题。
- 用户要求直接翻译、讲解或答案时，不强制测验。

### 写入授权

- 候选价值不等于正式写入授权。
- Query、Lint、词汇导出和一般精读默认对正式数据只读。
- `item` 已存在时，用户只授权“入库”不自动获得更新 `appear_count` / `last_seen` / `tags` 的权限。
- 只写当前明确授权的目标和字段，写后运行结构与来源校验。

### 四层地基

系统生成新例句时必须同时具备：

1. 用户当前措辞，或 unknown / mistranslated / missed 类明确错词证据。
2. approved / corrected 作文句型。
3. approved / corrected 作文词组。
4. verified 大纲 occurrence。

`source_sentence` 缺失时返回 `needs_context`。用户证据缺失时返回 `needs_user_evidence`。图谱缺失或过期时才返回 `needs_reference_graph`。输入门禁优先于图谱重建，避免无意义工作。

Selector 现已实际把用户证据纳入 `foundation_ready_for_generation_review`，不再只在文档中声明。

## A/B 设计

两组统一使用：

- Model：`gpt-5.6-sol`。
- Reasoning effort：`ultra`。
- 隔离 `CODEX_HOME`，不加载当前个人英语 skill。
- 只读 sandbox。
- 相同用例和任务证据。
- 唯一变量是迁移前快照与迁移后提示栈。

| 用例 | 目标 | 新版 | 旧版 | 主要差异 |
|---|---|---:|---:|---|
| E01 | 只解释本地词义 / 结构，不泄露答案 | 3 / 3 | 2 / 3 | 新版显式停在语言结构，旧版未说明答案保护边界 |
| E02 | 明确解锁 Q37，只读最小受保护块 | 3 / 3 | 1 / 3 | 新版只读 Q37；旧版工具输出读取了 Q36–Q40 完整 answer_key |
| E03 | 原样保留初译、不虚构错因、一轮一问 | 3 / 3 | 1 / 3 | 新版只留一个诊断问句；旧版未保留初译且同时有间接 / 直接两个问题 |
| E04 | 缺 source_sentence 时失败关闭 | 3 / 3 | 3 / 3 | 两者均正确；新版更短并符合聊天排版门禁 |

E03 通过三轮迁移迭代完成：

1. 第一轮发现未原样引用初译，并把同一个断点间接问一次、直接问一次。
2. 第二轮已原样引用，但判断区仍使用“能否”。
3. 第三轮将判断改为“当前证据不足以确认……”，最终 3 / 3 PASS。
